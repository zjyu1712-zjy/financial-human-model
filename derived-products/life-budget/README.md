更新日期：2026-11-28  
主仓库：[zjyu1712-zjy/life-budget](https://github.com/zjyu1712-zjy/life-budget)

## 与金融学人模型的关系

本余是金融学人模型研究探索的衍生产品，承接有限资源分配、个人偏好、生活取舍与复盘的研究方向，面向独立生活起步期的青年形成具体产品。

本目录保存产品说明与冻结规范快照；产品设计和开发在 life-budget 独立维护。原金融学人代码、模型文档和历史版本继续归档，不因更新本目录而恢复原项目开发。

本余采用其冻结规范中的产品规则，不自动沿用旧模型的全部指标、复杂公式或版本路线。旧原型的测试通过不代表本余已实现或已验证。

## 当前产品范围

面向 **22–28 岁刚进入社会、开始独立生活的年轻人**，**广州起步、大湾区试点**，围绕金钱与时间规划，帮助用户兼顾个人热爱、生活放松与储蓄准备。用户先规划，系统解释与建议，具体调整由用户自己决定。

| 模块 | 冻结设计 |
| --- | --- |
| 成本参考 | 同城同薪开支切片、生活方式情景切换、真实参考案例、支持税前转税后的跨城 Offer 实际结余对比。 |
| 智能预算 | 八项预算映射为生活保障、快乐生活、预防与缓冲、成长与投资四个心理账户，仅作规划分层；结合月内安全线与三个月应急储备目标。 |
| 消费决策与轻量目标 | 月内发薪与交租时点、未来半年现金流、消费前多路径比较、突发补录重算及 2–3 个心愿目标取舍联动。 |
| 并行时间配置 | 四项周规划与弹性留白、简短定性复盘、可选屏幕使用时间截图识别、钱—时双向参考预警。 |
| 个性化与陪伴 | 账单感受或具体场景选择、个人周期大额开支、可纠正的情绪与偏好记忆，以及可自定义猫咪的鼓励、安抚和成长回馈。 |

个人资源档案一次录入、全站复用；低频的 Offer 和租房通勤对比折叠为决策工具。技术按输入识别、确定性约束、可行情景排序、AI 约束式解释四层组织。核心金额由独立程序计算，用户可纠正系统理解与权重，前端不展示虚构幸福分。

## 研发阶段

独立 App 为最终方向，2027 前期先用 Figma 与可交互网页原型（Web MVP）降低验证成本。

- **P0 首版**：成本参考、八项预算与四个心理账户、偏好与现金流模拟、月末复盘、基础定制猫咪。
- **P1 迭代**：并行周时间复盘、钱—时预警、心愿联动、会员测试及租房通勤对比。
- **P2 扩展**：商业验证后的远期测试卡种与小机构 B 端展望。
- **P3 远期**：独立合规论证后的持牌机构支付、分账等合作。

上述为方案范围及实现路线，不表示全部功能已开发。首版不做健康检测、资金托管或代客理财。

## 商业与数据

收费结构为**免费版＋单次完整体验＋月度／季度／年度会员**；单次体验后 7 天内升级连续包月可全额抵扣体验费。正式价格由调研与真实购买测试决定，半年卡及双人卡属于远期测试，不纳入基准财务预测。

2028–2030 年经营预测以纯 C 端为基准，单次体验与会员分别测算，补充单位经济及敏感性分析；B 端仅作二期拓展情景，机构只接收匿名汇总指标。运营分别统计曝光、注册、激活、留存、转化和续费。

保留四层数据建设方案，新增三类数据物理分离、细分样本 n ≥ 30 且质检通过、优先展示中位数与 P25–P75 区间等规则。基础安全提示、数据导出与彻底删除始终免费，不出售个人消费数据。
