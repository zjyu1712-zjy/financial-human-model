# 外部生活环境指标：测量、预算传递机制与设计规则

版本：研究设计基线 v1.0（草案）· 2026-11-26

本文归档“金融学人项目研究交接”对话中的外部生活环境设计、字段和算例，并区分文献依据与项目设计规则。当前为研究草案，尚未开发、接入地图服务或开展真实用户验证。

## 1. 这个指标为什么需要

相同的收入和生活目标，在不同居住、工作环境下，可能对应不同的可选安排和实际费用。本指标拟回答两件事：某项省钱替换是否在当地存在、本人能否使用；如果可以使用，实际价格和路程是多少。

本版先研究三类条件：

- 居住与餐饮：可用厨房、冰箱、单位或学校食堂及使用资格。
- 通勤：公交、地铁等路线，公开票价与本人优惠资格。
- 平价采购与公共替代：周边商超、菜场，以及免费公共学习、休闲设施。

主输出仍是确定收支周期内各生活板块花多少钱、计划存多少钱，以及可以怎样调整。环境信息用于筛选和核算具体替换，不生成“环境总分”，不按城市均值直接分配个人预算。

## 2. 测什么，怎样取得

| 内容及字段 | 定义、单位与时间窗口 | 来源与填写方式 | 未知或离线处理 |
| --- | --- | --- | --- |
| 生活与工作区域 `living_work_zone` | 当前居住、工作或学习区域及生效期间；只取具体方案需要的范围 | 一次手动选区，或经授权单次定位；搬家、返乡或更换工作地点后手动更新 | 可跳过，不持续定位；改用条件确认，不凭区域未知推断没有设施 |
| 居住与餐饮条件 `home_dining_facilities` | 厨房、冰箱、食堂是否实际可用及准入资格；对应当前安排 | 期初可选确认 1–2 项，或在相关替换出现时再问 | 未知记为 `unknown`，不默认可用；无独立厨房不等于无可用厨房，共用设施需另行确认 |
| 通勤条件 `local_transit_options` | 路线、可达性、票价及本人实际优惠后价格；元/单程或往返、分钟，注明出行时段和查询日期 | 拟查询公开路线与票价作为起点；复用本人账单，并确认资格和实际适用条件 | 无接口时可简短自填；未确认的优惠或路线标待核对，不覆盖本人记录 |
| 本地公共替代 `local_public_alternatives` | 周边平价采购、公共学习与休闲设施的候选及本人实际可用性 | 只在需要替换时查询，或让用户确认已有可用设施 | 未触发不采集；“地图上有”不直接等于本人可用或本次免费 |
| 外部查询来源 `external_query_meta` | 来源名称、查询日期，区分外部参考值、本人历史记录和本次确认值 | 外部查询信息拟由系统记录；离线确认注明 `user_confirmed` 和适用日期 | 没有外部查询就不伪造来源；本人确认是数据来源类型，不等于系统已独立验证 |

这里列的是信息结构，不是要求用户一次填写五组题目。它测量的是环境条件、资格、价格与路程，不是心理构念；本版不涉及量表计分或心理总分换算。

### 为什么采用记录、查询与确认相结合

- 历史账单能提供本人已经支付的费用，但不能自动说明未来票价、食堂资格或营业情况仍相同。
- 外部查询可以减少找路线、查票价的负担，但设施标记不能替代对准入、营业时段和实际费用的确认。
- 是否有可用厨房、是否享受单位补贴等个人条件，拟用按需简短确认取得，不为此要求额外设备。

外部参考值与本人记录分开保存。发生冲突时提示核对日期和适用条件，不自动用公开均价覆盖账单，也不把过期账单无条件当作下一期价格。历史花费与未来预算估计仍按[金融资源](./financial-resource-spec.md)的口径区分。

### 低负担、离线与隐私规则

期初只提供可选选区和少量基础条件；其余内容在具体方案需要时再问。无外部接口、不授权定位或离线时，拟改用围绕该方案的 2–3 项条件确认，不影响基本预算核算；真实题目数和填写负担尚需试测。

区域变化由用户手动更新并标明生效期间，不采集持续轨迹。粗略区域不足以计算某条路线时，先说明还需要哪些地点信息，由用户决定是否提供；不把可选授权变成使用基本预算的前提。

地点、路线和生活规律也涉及隐私。具体地图服务、可发送的数据、保存与删除方式、接口授权和费用，实施前仍需确定。本次归档不含真实地址、定位或账单。

## 3. 输入怎样传递到输出

对话把这条路径称为“两阶段外部可行选择集与可达性筛选模型”。这里将其作为项目的组合设计描述：借鉴选择集与可达性研究，再使用金额、次数和时间进行核算；不是已经验证的同名算法。

**区域与设施条件 → 核对准入和路线，筛选环境上可用的候选 → 确认价格与额外耗时 → 结合时间、健康和生活底线检查 → 用户选择后，更新各板块开销与计划存钱。**

### 3.1 先判断环境条件是否满足

| 状态 | 如何处理 |
| --- | --- |
| 已确认不可用 | 排除这项具体替换，例如确认没有可用厨房时，不推荐依赖厨房的做饭方案 |
| 已确认环境上可用 | 进入价格、时间及其他条件的比较；不直接认定最终可执行 |
| 信息不足 | 保留待确认状态，不把未查到当作不存在，也不把未知当作通过 |

路线不直达，并不等于公共交通不可用；可换乘方案仍需核对实际耗时和费用。相应地，有地铁或食堂，也不代表其运行或营业时间符合用户的安排。

### 3.2 再计算具体方案的资金差额

对于已确认可比较的替换，可按以下账本关系说明本期差额：

`本期预计少花金额 = 本期替换次数 ×（原安排每次实际费用 − 替代安排每次实际费用）− 本期新增且未计入单价的相关费用`

这是项目的核算规则，不是心理或环境研究拟合出的系数。使用时需要统一单程/往返、每餐/每次和规划期口径；新增接驳费、会员费等只计一次。尚未确认的金额保留估计或待核对状态，不当成已实现节省。

同一笔原开销不能同时被两个互斥方案替换后再相加。某项费用已经包含在单价或原预算里，也不能再次扣除。未被用户选择的候选只用于比较，不改写实际账单。

其他条件不变时，已选择方案少支出的金额可以用于存钱目标或其他板块；它不是新增收入，也不能同时被记作增加储蓄和增加另一笔可花资金。基本开销、已确定付款与存钱目标沿用已有模块，不另建一套环境预算。

### 3.3 与其他指标分工

- [时间资源](./time-resource-spec.md)：检查额外步行、候车、换乘、采购或排队所需的净时间及具体时段。地图耗时只是起点，不再重复扣已有通勤或其他固定安排。
- [健康](./health-spec.md)：检查具体饮食、体力安排与已知限制是否冲突；环境上可达不等于身体上适合。
- [生活品质要求](./lifestyle-requirements-spec.md)：确认替代是否满足最低生活安排、本人优先级和可调整范围；便宜并不自动成为首选。
- [人际关系](./relationship-spec.md)：共用厨房、共同支出或需要协商的安排沿用既有确认与共同决定边界，不把别人的设施或资金视为本人可单独支配。
- [金融资源](./financial-resource-spec.md)：核对实际承担金额、付款日期与可动用资金。低价月卡等预付款仍需通过付款时点检查，不能仅看平均每次费用。

本版在当前居住、工作区域给定的情况下比较日常替换；换租、搬家等重大迁移不做自动推荐。这是本阶段的范围选择，不是某篇区位理论规定的结论。

## 4. 理论依据与核查范围

文献支持与具体规则分别记录。选择集、可达性及时间与现金的替代关系为设计提供依据；按需提问、离线使用、来源分存和固定住址范围是项目设计，尚无本项目效果验证。

### 4.1 选择集与准入条件

Manski（1977）的 *The Structure of Random Utility Models* 是选择集与随机效用模型的理论线索。本次核对了出版方题录，以及作者在访谈中回顾选择集生成研究的段落，未取得 1977 年论文全文。对本项目的启发是把“哪些方案进入考虑范围”与“进入后怎样比较”分开；原文具体形式与项目规则的对应仍待全文核对，不能直接等同于厨房、食堂和路线的确定性筛选。[出版方记录](https://link.springer.com/article/10.1007/BF00133443)、[作者访谈](https://tamer.scholars.harvard.edu/sites/g/files/omnuum7756/files/tamer/files/manski-final.pdf)

Hägerstrand（1970）的时间地理学讨论能力、耦合与权威/准入约束，为关注活动能否在给定时间、地点和准入条件下发生提供理论线索。本次核对了出版方题录与可检索的正文片段，未通读全文。本项目据此核对设施使用资格，并与时间资源衔接；不从这类概念直接推导个人省钱金额。[出版方记录](https://link.springer.com/article/10.1007/BF01936872)、[现出版方原文入口](https://www.sciencedirect.com/science/article/pii/S1056819023010321)

### 4.2 可达性需要专门测量

Handy 与 Niemeier（1997）讨论如何把可达性概念转为可应用的测度，提出测度设计框架并给出两个案例。本次核对了出版方及作者机构的题录与摘要，未取得全文，因此不把草案中的“设施存在 + 时间/费用 + 个体约束”写成已逐条核实的原文公式。本项目的准入、路线与本人确认清单属于具体设计。[出版方摘要与题录](https://journals.sagepub.com/doi/10.1068/a291175)、[作者机构记录](https://itspubs.ucdavis.edu/publication_detail.php?id=588)

### 4.3 实际支付价格与时间投入

Aguiar 与 Hurst（2007）利用商品扫描记录和时间日记研究购物、家庭生产与支付价格，考察购物频次、折扣利用等机制。这支持本项目同时核对实际价格与额外耗时，而不是给所有用户套统一省钱比例。它不直接证明周边设施增加就会因果性地降低个人开销，也不提供本项目的默认节省系数。[AEA 出版记录](https://www.aeaweb.org/articles?id=10.1257/aer.97.5.1533)、[作者公开原文](https://www.markaguiar.com/files/lifecycleprices.pdf)

本次阅读了作者公开正式论文中的研究设计、购物机制与主要结果段落，并与出版记录比对；未重新分析其原始数据。

### 4.4 区位研究与本版范围

Alonso（1964）的 *Location and Land Use* 保留为居住区位与土地成本的背景文献。本次核对到出版记录及包含家庭均衡、居住竞租曲线等内容的目录，未完成相关章节全文核查；不据此声称原书证明了“高迁移摩擦”，也不据此推出短期预算必须固定住址。本文的固定区域范围见 §3.3。[出版方记录与目录](https://www.degruyterbrill.com/document/doi/10.4159/harvard.9780674730854/html)

## 5. 虚构案例：先筛选，再核对每次能少花多少

以下数字和设施条件均为演示假设，不代表某座城市的现行票价或真实用户记录。

假设用户住在合租单间，并确认当前没有可用厨房，包括无法使用共用厨房；公司距住处 7 公里，有可用的直达地铁。地铁公开单程票价 4 元，用户确认本次适用八折优惠，实付 `4 × 0.8 = 3.2` 元；原本对应打车单程为 22 元。公司有补贴食堂，用户确认晚餐时段可用、员工资格适用，每餐 18 元；对应外卖每餐 35 元。

面对本期 300 元预算缺口，可作以下比较：

| 候选安排 | 环境检查 | 假设下的费用差额与后续检查 |
| --- | --- | --- |
| 改为在住处做饭 | 用户已确认没有可用厨房 | 排除依赖厨房的这项方案，不把未经核算的“省 300 元”计入预算 |
| 部分晚餐由外卖改食堂 | 确认食堂时段、资格和价格适用 | 每替换一餐少花 `35 − 18 = 17` 元；再核对饮食底线、额外耗时及愿意替换的餐数 |
| 部分打车改地铁 | 确认路线、时段与优惠适用 | 每替换一个单程少花 `22 − 3.2 = 18.8` 元；额外步行、候车等交给时间与健康检查 |

如果每周实际替换 3 个单程，且本例没有额外接驳等费用，则该周交通预计少花 `3 × 18.8 = 56.4` 元。“3 个单程”不是 3 次往返，也不自动代表一个月的次数。

整个规划期的替换餐数、单程次数和新增费用尚未确认时，不宣称已填平 300 元缺口。7 公里距离也不能代替具体路线耗时。只有方案通过相关条件检查、用户选择并确认次数后，才按 §3.2 纳入对应预算方案；实际节省仍需后续账单核对。
