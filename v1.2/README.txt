版本定位说明（2026-11-26）

本目录保留金融学人早期 1.2 可运行原型，比较工作、学习、休息等时间安排，输出现金、收入、学习效果和疲劳等变化。
项目当前研究方向已聚焦生活开销与储蓄分配：在确定收支周期内，比较各生活板块花多少钱、计划存多少钱及怎样调整。该资金分配功能尚未实现；1.2 不是这一新方向的已完成应用。

当前研究总览见 ../research/budget-allocation-progress.md，各指标的设计与证据见 ../research/ 目录及仓库根 README.md。
1.2 的方案对比、来源标记、按日期试行档案和复盘报告可作为后续开发参考；旧心理评分到效率、收入的假设公式不直接沿用为新方向参数。

此次只补充版本定位，不改本目录的原程序、模型公式、数据格式、离线文件或已有验收记录，不重新构建发布包。
以下原有使用与交接说明完整保留。其中“本地交付”“当前报告”等表述对应各自的历史交付阶段；版本发布状态以 GitHub Releases 为准，历史测试结果不代表当前资金分配功能或真实使用效果已通过验证。

先有一个参考，再每天记实际睡了多久、睡前有多累、睡得怎样。
记录不足就保留原设置；记录够了才提供待确认的参考。
