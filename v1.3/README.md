# 金融学人 1.3 · 工作安排决策

帮助你比较一项工作安排变化的财务结果、生活代价和行动条件。1.2 原版和实验工具完整保留在相邻的 `v1.2/` 目录，本版使用新收入规则与独立数据空间。

## 打开与转发

直接保存并打开 `financial-human-model-standalone.html`。样式和程序都已内置，可复制、改名、发给别人，用 Edge、Chrome 等现代浏览器离线打开。聊天软件预览可能不运行程序，请下载后用浏览器打开。

开发入口 `index.html` 需要同目录的 `styles.css` 和 `app.offline.js`。程序不连接账户、不上传数据；首次打开用示例起步，需替换成自己的实际数据。所有金额均为税后人民币。

## 一次完整决策

1. 说明选择：填写标题、观察起点和6/12/24个月观察期。
2. 确认现状：现金、投资资产、债务与计划还本、月支出、收入约定和每周时间，设定现金/睡眠/工作底线。
3. 改变安排：填写开始月份、持续月份、一次性费用、期间的收入/支出/时间。期间结束后恢复原安排。
4. 对照结果：基础假设与指定月份市场下跌情景共享市场路径；查看现金、投资资产、债务、净资产、首次触线月份和时间交换。现金不足时停止该路径并显示缺口，不自动借款或卖出资产。
5. 记录决定：写下当前倾向、理由、行动/退出条件和回看日期，核对来源后存档。

身体、认知、情绪、关系和价值取舍为用户观察与待验证假设，保留在决策与报告中，不直接折算为收入或投资收益。可比较违反个人底线的方案，系统列明差额/条件，不替你选择。

## 档案、报告与备份

- 保存的决策包含当时输入和基础/下跌两种计算快照。修改草稿不会改写档案；复盘只追加实际观察。
- 报告为独立离线 HTML，默认显示一页摘要，完整依据可展开；打印样式只打印摘要。长文本在摘要中摘录，全文仍在报告附录及数据备份中。
- 每条复盘的收支请按你注明的观察范围填写，原预测不自动校准。最多100条档案，每条50次复盘。
- “导出全部数据”含档案和当前草稿；未完成的无效输入也可备份。导入前会显示预览，确认替换前自动发起旧数据备份下载。
- 浏览器存储被禁或空间不足时，变化只在当前打开中有效，请导出保存。换文件位置、浏览器或设备后需重新导入。
- 若草稿损坏但档案有效，会恢复有效输入与全部档案。整个保存内容无法校验时，保护原始内容免于普通编辑覆盖，并提供原始备份下载。
- 1.2 文件不会自动转换；新旧版本可分别打开和备份。本版不改写已有1.2记录。

## 开发

无外部依赖。Node 20及以上：

```sh
npm test
npm run build
```

构建从 `src/finance.js`、`src/decision.js`、`src/app.js` 生成 `app.offline.js` 与单文件版，不直接修改生成文件。测试覆盖计酬、市场路径、记账、变化时点、不可行路径、输入边界、来源、档案/复盘、报告转义、导入、存储失败及独立打包。

本版只比较已明确的工作安排，不估计学习后的涨薪概率，不纳入自动借贷/变现、住房估值、税务优化或证券买卖推荐。金融假设和计算口径见 `MODEL_SPEC.md`。
