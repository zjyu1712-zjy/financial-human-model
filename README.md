# 金融学人模型实验台

调整初始状态、行动和模型参数，与固定基准比较六系统状态、效用、成本、约束及 4 / 12 周路径。

## 模型共同创作者

金融学人模型由 [@zjyu1712-zjy](https://github.com/zjyu1712-zjy) 与 [@3748019-gif](https://github.com/3748019-gif) 共同构思和搭建。

本仓库提供该模型的开源实现与交互式实验台。

## 打开与使用

直接在普通浏览器打开 `index.html`。它与 `styles.css`、`app.offline.js` 放在同一目录即可运行，运行时没有外部依赖和网络请求。

1. 点击“设为基准”，固定当前输入与参数。
2. 调整状态、行动或四组参数；数值框可直接输入，滑杆用于连续探索。
3. 查看初始净值与成本差异，切换雷达的初始／末期状态。
4. 选择 4 或 12 周，比较同一周期下的实线实验组与虚线基准。
5. 在“相对基准的改动”和“从输入到结果”中查看差值和计算依据。

“恢复基准”复制基准到实验组；“实验组恢复默认”重置输入和参数；“参数恢复默认”保留当前状态、行动及冲击。三项操作都保留固定基准与所选周期。实验保留在当前页面，刷新后恢复默认；当前版本没有历史存储与导出。

## 开发与检查

Node.js 18 或更高版本。无需安装 npm 依赖。

```sh
npm test
npm run build
npm start
```

本地预览地址为 `http://127.0.0.1:4173`。服务只提供三个网页文件，不暴露项目文档或源码目录。修改 `src/` 后运行 `npm run build`，更新离线脚本。

## 可调参数

| 参数组 | 数量 | 作用 |
| --- | ---: | --- |
| 效用权重 | 6 | 自动归一化后计算效用；至少一项权重大于零 |
| 成本系数 | 5 | 四类系统成本与单列的预算扩展项 |
| 约束参数 | 9 | 软阈值、硬线、容量倍率；总时间硬线固定为 100% |
| 状态转移 | 4 | 休息对身体、学习对认知、工作对金融资源、冲击留存率 |

无效或暂时清空的输入不覆盖最近一次有效计算，字段显示原因。修正后更新结果。存在未修正字段时，“设为基准”暂停使用。

## 计算口径

原模型由六系统状态、资源分配、效用、四类成本与动态反馈组成。本实验台采用现有原型的可计算近似：0–100 状态指标、线性效用分项、归一化权重、阈值成本及独立状态转移。

- `Des_t` 保留价值匹配与比较压力两个分量；雷达值为 `0.65 × 匹配 + 0.35 × (100 − 压力)`。
- `EmotionCost` 在本实现中以情绪负荷和调节容量聚合近似。原文六类功能损失用于解释该概念。
- 预算压力成本是原型扩展项，界面单列，计入成本总和；原文四类成本的定义保持独立。
- `Net` 是效用减去成本的结果；状态转移由各系统自己的输入、损耗与冲击决定。修改效用权重只改变净值组成，修改转移参数改变路径。
- 时间超过 100% 记为超过硬线；等于硬线按软阈值继续分类。实验保留越界情景以观察后果。
- 预算压力使用无量纲指标，允许超过 100；容量和状态按各自规则截断。
- 状态曲线采用固定行动与逐周衰减冲击。参数为研究初始假设，尚未用个体数据校准。

计算公式、当前代入值和第一周结果均在页面底部展开查看。数值对照保留负净值和高成本，图形按各自标尺显示。
