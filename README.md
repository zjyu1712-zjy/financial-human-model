# 金融学人

个人辅助决策系统。当前研究聚焦生活开销与储蓄之间的资金分配：在一定期间内，保障基本生活和已确定的付款义务，比较各板块预算、存钱进度与具体调整。

## 当前研究进展

[生活开销与储蓄分配研究进展](./research/budget-allocation-progress.md)汇总截至 2026 年 11 月 24 日已确认的输出方向、生活板块、目标取舍、输入定义和低填写负担的数据获取方式。

[情绪模块定稿基线 v1.0（2026-11-25）](./research/emotion-module-spec.md)记录账单候选线索初筛、规划期初简短复盘、预算缓冲与止损安排、软承诺提醒及执行时间校验；属于研究设计初步定稿，保留参数与实际效果的待验证事项。

[时间资源指标设计基线 v1.0（2026-11-25）](./research/time-resource-spec.md)整理四类时段、分日类型的睡眠底线、低填写负担的获取方式，以及时间如何通过支出替代方案影响预算与储蓄；附原始文献和虚构对比案例。属于研究设计，尚未开发或实测；其中的时段规则细化并更新情绪文档原有的每周总量校验。

研究文档保留指标定义、模型机制、文献依据、案例与验证进度；汇报稿等沟通材料单独交付，不随研究文档上传。

- 已确认设计：底线优先，生活安排与存钱目标并列；资金不足时比较保留存钱进度、保留期望生活和双方适度调整三类方案。
- 输入研究：情绪和时间资源已形成上述研究设计基线；健康、人际关系、认知、金融资源、生活品质要求继续逐项研究，外部生活环境仍作为候选方向保留，未作统一裁剪。
- 当前阶段：研究定义与规则整理。资金分配功能尚未实现；首发人群、市场需求验证和产品形态待确定。

## 1.2 可以做什么

1. 选择目标：多学一点、少累一点、增加收入。
2. 填写自己的安排，设定不能牺牲的底线。
3. 直接对照方案，查看时间投入、收获与损失、逐周变化和底线余量。
4. 选一个方案试行，记录实际情况，再回来修改。
5. 在“底层模型”查看完整公式、变量与参数；修改后自动更新结果。

“看完整示例”保留固定体验入口，不覆盖自己的输入。切换页面或返回修改时，已填内容会保留。

### 1.2 更新

- 全站改用更日常的表达，专业定义集中在“底层模型”。
- 新增睡眠与精力填写引导：定参考、记实际、看变化。
- 根据实际记录提出参考时长、近期状态和恢复设置的调整建议，用户确认后才采用。
- 保留个人睡眠需求、睡眠债和恢复速度模型，以及与旧模型的对照。

模型用于比较假设下的取舍，不是健康诊断或收益保证；公式与适用边界见版本内说明。
