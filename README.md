## 模型衍生产品：本余

**本余——基于AI与行为经济学的青年生活资源智能规划平台**，面向 22–28 岁刚进入社会、开始独立生活的年轻人，围绕金钱与时间分配、个性化定制和猫咪情绪陪伴，帮助用户兼顾个人热爱、生活与储蓄准备。

个人辅助决策系统。当前研究聚焦生活开销与储蓄之间的资金分配：在一定期间内，保障基本生活和已确定的付款义务，比较各板块预算、存钱进度与具体调整。

## 当前研究方向：生活开销与储蓄分配

[生活开销与储蓄分配研究进展](./research/budget-allocation-progress.md)汇总截至 2026 年 11 月 26 日已确认的输出方向、生活板块、目标取舍、八个候选输入方向及其证据状态，并说明与早期原型的关系。

[情绪模块定稿基线 v1.0](./research/emotion-module-spec.md)记录账单候选线索初筛、规划期初简短复盘、预算缓冲与止损安排、软承诺提醒及执行时间校验；属于研究设计初步定稿，保留参数与实际效果的待验证事项。

[时间资源指标设计基线 v1.0](./research/time-resource-spec.md)整理四类时段、分日类型的睡眠底线、低填写负担的获取方式，以及时间如何通过支出替代方案影响预算与储蓄；附原始文献和虚构对比案例。属于研究设计，尚未开发或实测；其中的时段规则细化并更新情绪文档原有的每周总量校验。

[金融资源指标设计基线 v1.0](./research/financial-resource-spec.md)整理可动用资金、收入确定性、付款日期、低频支出与信用消费的核算方式，说明金融资源怎样限定预算总额和付款时点，并附“整期够用、付款日不足”的虚构案例。

[生活品质要求指标设计基线 v1.0](./research/lifestyle-requirements-spec.md)整理最低生活安排、期望优先级、存钱目标和可接受调整，说明它们怎样形成三类预算取舍；附理论依据和虚构对比案例。两份新文档均为研究草案，保留 P1 优先级边界等尚未确定的事项，尚未开发或真实用户验证。

[人际关系指标设计基线 v1.0](./research/relationship-spec.md)整理共同支出的本人份额、已约定支持与借还、共同决定标记，以及人情礼金和日常社交如何进入预算；附理论依据、虚构案例和待确认规则。属于研究草案，尚未开发或真实用户验证。

[健康指标设计基线 v1.0](./research/health-spec.md)整理已确认的健康相关费用、医保与既有应急金核对，以及睡眠、疲劳和具体活动限制怎样影响预算与省钱方案；与时间资源共享睡眠记录，设备数据仅作可选辅助。附原始文献和虚构案例，题项、提示规则与实际效果仍待验证。

[外部生活环境指标设计基线 v1.0](./research/external-environment-spec.md)整理餐饮设施、通勤和公共替代条件，说明如何按实际可用性、本人确认的价格与耗时筛选省钱方案；支持一次选区、按需确认及离线使用的设计。附文献核查范围和虚构案例，接口、填写负担与实际效果仍待验证。

[认知指标设计基线 v1.0](./research/cognition-spec.md)整理事前预测与实际支出的对照、分期等费用解释和简版/明细版呈现，说明如何辅助预算调整与跨期比较；区分预测、目标和认知能力，不采用认知总分。附文献核查范围与虚构算例，提示规则、界面与实际效果仍待验证。

研究文档保留指标定义、模型机制、文献依据、案例与验证进度；汇报稿等沟通材料单独交付，不随研究文档上传。

- 已确认设计：底线优先，生活安排与存钱目标并列；资金不足时比较保留存钱进度、保留期望生活和双方适度调整三类方案。
- 输入研究：情绪、时间资源、金融资源、生活品质要求、人际关系、健康、外部生活环境和认知八个候选方向已形成首轮研究设计基线；各项设计的适用范围与实际效果仍待核查，不代表全部为必填输入或已实现功能。
- 当前阶段：研究定义与规则整理。资金分配功能尚未实现；首发人群、市场需求验证和产品形态待确定。

## 当前方向与早期原型的关系

共同关注的问题是：有限资源能支持怎样的生活，选择会带来哪些收益和代价。具体决策任务和计算路径已经发生变化：

| 对照 | 早期 1.2 原型 | 当前资金分配研究 |
| --- | --- | --- |
| 用户比较什么 | 工作、学习、休息等时间安排 | 各生活板块开销、计划存钱金额与具体调整 |
| 主要输出 | 现金、收入、学习效果、疲劳轨迹等变化 | 元/规划期的预算与目标进度、付款缺口及可执行调整 |
| 计算路径 | 个人状态、假设效率公式和逐周状态转移 | 金额与日期核算、生活底线与偏好、具体方案的执行条件 |
| 当前状态 | 已有可运行原型与工程验收记录 | 已形成研究设计草案，尚未实现和开展真实用户验证 |

方案对比、输入来源标记、按日期试行档案和复盘报告可作为后续开发的参考。旧版心理评分到效率、收入的假设公式不直接沿用；原程序、模型规范和验收记录保留，不能把旧版测试通过当成新资金分配功能已经完成。

[1.3 工作安排决策](https://github.com/zjyu1712-zjy/financial-human-model/pull/3)截至 2026 年 11 月 26 日仍在待合并的独立方案中，也不代表当前资金分配研究已经实现。

## 1.2 原型可以做什么

1. 选择目标：多学一点、少累一点、增加收入。
2. 填写自己的安排，设定不能牺牲的底线。
3. 直接对照方案，查看时间投入、收获与损失、逐周变化和底线余量。
4. 选一个方案试行，记录实际情况，再回来修改。
5. 在“底层模型”查看完整公式、变量与参数；修改后自动更新结果。

“看完整示例”保留固定体验入口，不覆盖自己的输入。切换页面或返回修改时，已填内容会保留。
