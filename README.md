# 金融学人

把工作、学习和休息之间的取舍放在一起看：先选想改善的问题，再比较时间、收入和疲劳的变化，选一个安排试一周。

- [下载 1.2 离线发布包](https://github.com/zjyu1712-zjy/financial-human-model/releases/tag/v1.2.0)

网页离线运行，无需安装依赖。输入与记录保存在当前浏览器，可以导出备份。仓库和发布包中的记录样本用于测试，不是用户的实际记录。

## 可以做什么

1. 选择目标：多学一点、少累一点、增加收入。
2. 填写自己的安排，设定不能牺牲的底线。
3. 直接对照方案，查看时间投入、收获与损失、逐周变化和底线余量。
4. 选一个方案试行，记录实际情况，再回来修改。
5. 在“底层模型”查看完整公式、变量与参数；修改后自动更新结果。

“看完整示例”保留固定体验入口，不覆盖自己的输入。切换页面或返回修改时，已填内容会保留。

### 1.2 更新

- 全站改用更日常的表达，专业定义集中在“底层模型”。
- 新增睡眠与精力填写引导：定参考、记实际、看变化。
- 根据实际记录提出参考时长、近期状态和恢复设置的调整建议，用户确认后才采用。
- 保留个人睡眠需求、睡眠债和恢复速度模型，以及与旧模型的对照。

模型用于比较假设下的取舍，不是健康诊断或收益保证；公式与适用边界见版本内说明。
